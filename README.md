# VSCode Menu

A React-based file explorer menu inspired by the VS Code sidebar.

## Features

- Nested file and folder structure
- Expand and collapse folders
- Select files and folders
- Add new files to selected folders
- Recursive rendering of nested items
- Dynamic menu state management

## Technologies

- React 18
- Vite
- SCSS
- React Router DOM
- clsx

## Run Locally

```bash
npm install
npm run dev
```
